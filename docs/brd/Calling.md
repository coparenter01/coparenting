## 2. Purpose and scope

**2.1 Purpose.** This module lets parents talk inside the app without sharing personal phone numbers, with an optional recording that is made only with consent.

**2.2 Objectives this module supports.** Objective IDs come from Common BRD section 2.3.

| ID     | How this module supports it                                                                                                            |
|--------|----------------------------------------------------------------------------------------------------------------------------------------|
| OBJ-01 | The call log, the consent log, the recordings and the transcripts are part of the court-ready record (CLL-01, CLL-02).                 |
| OBJ-05 | A parent keeps their phone number and location private, and in Safety Mode calling is off until the user turns it on (CLL-03, CLL-01). |

**2.3 In scope.** The three features CLL-01 to CLL-03 listed in section 5.

**2.4 Out of scope for this BRD.** These items belong to another module or to a later decision.

| Item                                                                              | Where it belongs                                                                                  |
|-----------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------|
| Alerts for an incoming call and a missed call                                     | Notifications (NTF). This module gives the events (CR-01).                                        |
| The export format of call records and recordings                                  | Records and Court (REC).                                                                          |
| Plan rules for calls                                                              | Billing and Plans (Billing BRD, decision Q-01).                                                   |
| The design of Safety Mode                                                         | Safety and Privacy (SAF-01).                                                                      |
| Read-only access for professionals                                                | Professionals and Access (PRO-01, Phase 2).                                                       |
| Calls to or from a phone number, and calls with a co-parent who is not on the app | Not in this BRD (decision Q-05). The Accounts BRD sends texts and emails to that person (ACC-04). |
| Calls with a Child account or a Third party, group calls and screen sharing       | Not in this BRD (decision Q-05).                                                                  |
| Voicemail                                                                         | Not in this BRD (decision Q-05). A parent sends a message instead (Messaging).                    |
| Legal advice                                                                      | Out of scope (Scope document 4.2).                                                                |

**2.5 Release phases of this module.** Phase 2 (web): CLL-01, CLL-02 and CLL-03. The phase of each feature is a proposal (Scope document 4.4).

## 3. Users and roles

Roles are defined in Common BRD 7.1 and the shared permission matrix is in Common BRD 7.2. The table shows what each role does in this module.

| Role                  | What they do in this module                                                                                                                         |
|-----------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------|
| Parent                | Turns calling settings on or off, places and answers calls, agrees to a recording, and plays or downloads the recordings of the calls they were on. |
| Co-parent             | The same as the Parent, once linked.                                                                                                                |
| Professional          | Reads the call records and recordings that a parent shares (PRO-01). Cannot call.                                                                   |
| Support staff         | Cannot hear recordings or read transcripts (Common BRD 7.1).                                                                                        |
| Platform admin        | Runs the system. Cannot edit or delete a call record or a recording.                                                                                |
| Third party and Child | No feature in this module (decision Q-05).                                                                                                          |

Permissions for module data: Common BRD 7.2 has no row for calls. Call records, recordings and transcripts follow the row Records and exports: the Parent and the Co-parent have CR, and the Professional has R (shared only). Nobody can edit or delete a call record, a recording or a transcript (CR-04).
