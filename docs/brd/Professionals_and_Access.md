## 2. Purpose and scope

**2.1 Purpose.** This module lets a parent bring in an attorney, a mediator or a therapist without giving that person control of the account. The professional reads what the parent chooses to share and cannot post or change anything. In Phase 3 a parent can also send one selected message to a professional.

**2.2 Objectives this module supports.** Objective IDs come from Common BRD section 2.3.

| ID     | How this module supports it                                                                                                                             |
|--------|---------------------------------------------------------------------------------------------------------------------------------------------------------|
| OBJ-01 | A professional can read the court-ready records that the parent shares, such as certified exports (PRO-01).                                             |
| OBJ-04 | Professional access is a paid extra of the Household plan (Scope document decision 9).                                                                  |
| OBJ-05 | The parent chooses what to share, can stop access at any time and sees when the professional looked. Hiding rules for Safety Mode still apply (PRO-01). |

The Scope document links no pain point to this module. BR-24 has no pain point source and is a design proposal (Scope document section 9).

**2.3 In scope.** The two features PRO-01 and PRO-02 listed in section 5.

**2.4 Out of scope for this BRD.** These items belong to another module or to a later decision.

| Item                                                                    | Where it belongs                                                                                                                                                                                                      |
|-------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Sign-in, two-factor sign-in, password reset and the account of a person | Accounts and Onboarding (ACC-01, ACC-09, ACC-10). A professional account follows the same rules.                                                                                                                      |
| What an item contains and who can see it                                | Messaging (MSG), Calendar and Parenting Time (CAL), Expenses and Payments (EXP), Children and Documents (DOC), Records and Court (REC). This module only lets a professional read it under the same visibility rules. |
| Certified exports, affidavits and the legal hold                        | Records and Court (REC). A professional reads a certified export that a parent shares.                                                                                                                                |
| Human mediation inside the app by a licensed mediator of a partner      | Messaging (MSG-12, Phase 3). The mediator answers in the mediation thread.                                                                                                                                            |
| Plan rules and prices                                                   | Billing and Plans (BIL). This module only says that professional access is a paid extra.                                                                                                                              |
| Sending invites and alerts                                              | Notifications (NTF-06). This module gives the events.                                                                                                                                                                 |
| Checking that a professional holds a licence                            | Not in this BRD. The parent chooses who to invite.                                                                                                                                                                    |
| Court or agency staff as users                                          | Out of scope for now (Scope document 4.2, decision 13). They use the public pages of Records and Court.                                                                                                               |
| Legal advice                                                            | Out of scope for now (Scope document 4.2).                                                                                                                                                                            |

**2.5 Release phases of this module.** Phase 2 (web): PRO-01. Phase 3 (later): PRO-02. This matches the Scope document, which lists 1 Phase 2 feature and 1 Phase 3 feature for this module. The phase of each feature is a proposal (Scope document 4.4).

## 3. Users and roles

Roles are defined in Common BRD 7.1 and the shared permission matrix is in Common BRD 7.2. The table shows what each role does in this module.

| Role                  | What they do in this module                                                                                                                                                                                                                                  |
|-----------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Parent                | Invites professionals, chooses what each one can see, shares single items, stops access, reads the access log, and in Phase 3 sends one selected message to a professional.                                                                                  |
| Co-parent             | The same as the Parent for their own professionals, once linked. Each parent has their own professionals, and a parent does not see the professionals of the other parent (decision Q-04, open question Q-16).                                               |
| Professional          | An attorney, a mediator or a therapist invited by a parent. Reads what the parent shares. Cannot post, edit, delete or invite. One account can serve many parents. The mediator in a mediation thread of MSG-12 is the only exception (Messaging BRD CR-03). |
| Support staff         | No access to shared records. May see the status of an invite and of an access to help with a sign-in problem, and cannot read parent messages (Common BRD 7.1).                                                                                              |
| Platform admin        | Runs the system. Access is logged (Common BRD 7.1).                                                                                                                                                                                                          |
| Third party and Child | No feature in this module.                                                                                                                                                                                                                                   |
| Court or agency staff | Not users of the app (Scope document 4.2, decision 13).                                                                                                                                                                                                      |

Permissions for module data: Common BRD 7.2 gives the Professional R (shared only) on household and children, messages, calendar events, expenses and records and exports. It has no row for the access settings, the item shares, the access log or the forwarded messages of this module. CR-01 asks to add them. A professional never gets a right to create, update or delete (BR-24).
