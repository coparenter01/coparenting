## 2. Purpose and scope

**2.1 Purpose.** This module connects the account of a parent with their child support case, so that agency facts and the parent's own records sit side by side. It is the main difference between this app and the 11 apps that were reviewed. None of them connects to a state child support system.

**2.2 Objectives this module supports.** Objective IDs come from Common BRD section 2.3.

| ID     | How this module supports it                                                                                                                           |
|--------|-------------------------------------------------------------------------------------------------------------------------------------------------------|
| OBJ-01 | The proof package, the hearing packet and the exports with agency data are part of the court-ready record (CSS-06, CSS-11).                           |
| OBJ-02 | This module is the objective: it connects to US child support systems through an API and a batch process, read-only first (CSS-01 to CSS-07, CSS-12). |
| OBJ-03 | Fixes the High-rated pain points P19, P20 and P22 (CSS-01 to CSS-07).                                                                                 |
| OBJ-05 | Agency data stays private to the linked parent, and a family violence flag can offer Safety Mode (CSS-08, CSS-13).                                    |

**2.3 In scope.** The eleven features CSS-01 to CSS-11 listed in section 5, and the proposed features CSS-12 (the sync engine) and CSS-13 (sharing one agency item). CSS-12 and CSS-13 are needed by the Scope document design in section 8 and by the Calendar and Notifications BRDs (CR-01).

**2.4 Out of scope for this BRD.** These items belong to another module or to a later decision.

| Item                                                                                                                              | Where it belongs                                                                                                                                                        |
|-----------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Replacing the child support system or doing its work. The app does not calculate support orders, manage cases or enforce payment. | Out of scope for now (Scope document 4.2).                                                                                                                              |
| Paying child support through the app                                                                                              | Expenses and Payments (EXP). The app links to the state payment page and records the payment there. It never replaces the official channel (Scope document decision 8). |
| Connecting more than one state, and linking more than one case for a parent                                                       | Not in this BRD (decision Q-17).                                                                                                                                        |
| Agency staff as users of the app                                                                                                  | Out of scope for now (Scope document decision 13).                                                                                                                      |
| Splitting costs by the court order                                                                                                | Expenses and Payments (EXP-05).                                                                                                                                         |
| Reminder sending, and the alerts for failed loads                                                                                 | Notifications (NTF) and the operations team. This module gives the dates and the events.                                                                                |
| The calendar entries themselves                                                                                                   | Calendar and Parenting Time (CAL-01). This module puts the agency items there.                                                                                          |
| The design of Safety Mode                                                                                                         | Safety and Privacy (SAF-01).                                                                                                                                            |
| The export format and the public check page                                                                                       | Records and Court (REC).                                                                                                                                                |
| Legal advice                                                                                                                      | Out of scope (Scope document 4.2).                                                                                                                                      |

**2.5 Release phases of this module.** Sync phase 1 (read-only): CSS-01, CSS-02, CSS-03, CSS-04, CSS-05, CSS-07, CSS-12 and CSS-13. Sync phase 2 (two-way): CSS-06, CSS-08, CSS-09 and CSS-10. Phase 3 (later): CSS-11. Sync phase 1 needs EXP-07, CAL-01, NTF-04 and ACC-01 from the first release (Scope document 4.3). Every feature also needs the first state, its API and batch specifications, and its approvals (decisions Q-01, Q-02 and Q-15). The phase of each feature is a proposal (Scope document 4.4).

## 3. Users and roles

Roles are defined in Common BRD 7.1 and the shared permission matrix is in Common BRD 7.2. The table shows what each role does in this module.

| Role                  | What they do in this module                                                                                                         |
|-----------------------|-------------------------------------------------------------------------------------------------------------------------------------|
| Parent                | Links their own case, reads the agency data, refreshes it, shares one item, and unlinks. In Sync phase 2 sends proof to the agency. |
| Co-parent             | Sees nothing from the agency unless the linked parent shares one item (decision Q-06).                                              |
| Professional          | Reads an item that the linked parent shares (Common BRD 7.2). Cannot link or send.                                                  |
| Support staff         | Sees that a link exists and the load log. Never sees the agency values (Common BRD 7.2).                                            |
| Platform admin        | Runs the system and the loads. Access is logged. Never reads the agency values.                                                     |
| Agency staff          | Not users of the app (Scope document decision 13).                                                                                  |
| Third party and Child | No feature in this module.                                                                                                          |

Permissions for module data: Common BRD 7.2 gives the Parent CRUD (own) and nobody else any right on the child support link. Sharing one item with the co-parent or a professional is the only way another person sees agency data (CSS-13).
