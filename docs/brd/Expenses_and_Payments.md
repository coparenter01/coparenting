## 2. Purpose and scope

**2.1 Purpose.** This module tracks what each parent spends on the children and who owes what. It also holds the child support payments that a parent records, which the Child Support Sync module compares with the agency record.

**2.2 Objectives this module supports.** Objective IDs come from Common BRD section 2.3.

| ID     | How this module supports it                                                                                                                                 |
|--------|-------------------------------------------------------------------------------------------------------------------------------------------------------------|
| OBJ-01 | Expenses, receipts, reimbursement requests and recorded payments, with their history, are part of the court-ready record (EXP-01, EXP-02, EXP-03, EXP-07).  |
| OBJ-02 | The parent-recorded child support payment is the base for the comparison with the agency record. Sync phase 1 needs EXP-07 from the first release (EXP-07). |
| OBJ-03 | Fixes the High-rated pain point P20 in the first release (EXP-07). Also addresses the Medium-rated P21 and P07 (EXP-03, EXP-04, EXP-05, EXP-08).            |
| OBJ-04 | Expenses and receipts are in the free core plan for both parents (Scope document decision 9).                                                               |

**2.3 In scope.** The fifteen features EXP-01 to EXP-15 listed in section 5.

**2.4 Out of scope for this BRD.** These items belong to another module or to a later decision.

| Item                                                                                                           | Where it belongs                                                                                                                  |
|----------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------|
| Comparing agency payments with the payments a parent recorded, mismatch flags, and sending proof to the agency | Child Support Sync (CSS-03, CSS-06). This module holds the record and its status field (EXP-07).                                  |
| The agency view of balance, arrears and due dates                                                              | Child Support Sync (CSS-04).                                                                                                      |
| Paying child support that goes through the agency                                                              | The state payment page. The app links to it and records the payment. It never replaces it (Scope document decision 8).            |
| Moving money in the MVP                                                                                        | Not in the MVP. The app records payments and does not move money (Scope document decision 8). Money transfer is Phase 3 (EXP-08). |
| Plan limits, storage price and which extras are paid                                                           | Billing and Plans (BIL). This module only uses the storage limits of the plan.                                                    |
| Sending alerts and reminders                                                                                   | Notifications (NTF). This module gives the events and dates.                                                                      |
| The export format of expense and payment records                                                               | Records and Court (REC).                                                                                                          |
| How a child is added to the household                                                                          | Children and Documents (DOC-01). This module uses the Child entity in Common BRD 8.3.                                             |
| Pet schedules                                                                                                  | Calendar and Parenting Time (CAL-11). Only the expense category Pet is in this module.                                            |
| Calculating a child support order, managing a case or enforcing payment                                        | Out of scope for now (Scope document 4.2).                                                                                        |
| Legal advice                                                                                                   | Out of scope for now (Scope document 4.2).                                                                                        |
| Agency staff as users                                                                                          | Out of scope for now (Scope document 4.2, decision 13).                                                                           |

**2.5 Release phases of this module.** MVP (web): EXP-01, EXP-02, EXP-03, EXP-06 and EXP-07. Phase 2 (web): EXP-04, EXP-05 and EXP-09. Phase 3 (later): EXP-08, EXP-10, EXP-11, EXP-12, EXP-13, EXP-14 and EXP-15. This matches the Scope document, which lists 5 MVP features, 3 Phase 2 features and 7 Phase 3 features for this module. The phase of each feature is a proposal (Scope document 4.4).

## 3. Users and roles

Roles are defined in Common BRD 7.1 and the shared permission matrix is in Common BRD 7.2. The table shows what each role does in this module.

| Role                             | What they do in this module                                                                                                                                                                                                                                                  |
|----------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Parent                           | Records expenses, attaches receipts, shares items with the co-parent, sends and marks reimbursement requests, and records child support payments. In Phase 2: enters split rules, sees the running balance and opens disputes. In Phase 3: pays through the payment partner. |
| Co-parent                        | The same as the Parent, once linked. Answers reimbursement requests.                                                                                                                                                                                                         |
| Professional                     | Reads the expenses and payment records that a parent shares (Common BRD 7.2). Cannot post. Access comes with PRO-01, Phase 2.                                                                                                                                                |
| Support staff and Platform admin | No feature in this module. Common BRD 7.2 gives them no access to expenses.                                                                                                                                                                                                  |
| Third party and Child            | No feature in this module. Common BRD 7.2 gives a Third party no access to expenses.                                                                                                                                                                                         |
| Agency staff                     | Not users of the app (Scope document 4.2, decision 13).                                                                                                                                                                                                                      |

Permissions for module data: Common BRD 7.2 gives the Parent and the Co-parent CRU on expenses and the Professional R (shared only). It has no delete right, so this module voids entries and never deletes them (decision Q-01). A change is a new version and the earlier version stays (NFR-05). A private entry is seen only by the parent who created it. Common BRD 7.2 has no row for child support payments that a parent records, so a new row is proposed (CR-01). Common BRD 7.2 also keeps the child support link private to the parent who linked it, and this module follows the same rule for the payments a parent records (decision Q-09).
