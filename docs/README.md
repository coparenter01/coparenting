# Documentation map

- Start with `plan/` (how we build) and `manual/00-INTRO.md` (what we build).
- For a module, read `requirements/<CODE>.md` and `manual/<CODE>.md` together, then the wireframes listed for it in `plan/07-screen-map.md`.
- `requirements/APPENDIX.md`: traceability matrix and parameter index (all numbers such as time limits).
- `manual/APPENDIX.md`: screen index, user action index, business rules register.
- `brd/`: background only; the plan and the two files above take priority.
